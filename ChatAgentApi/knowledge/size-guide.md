# Bảng size tham khảo

Lưu ý: số đo có thể chênh lệch nhẹ theo form từng sản phẩm.

## Áo thun/áo hoodie
- Size S: form nhỏ
- Size M: form vừa
- Size L: form rộng

## Quần short/quần jean
- Size S/M/L theo vòng eo và form mặc.

Khuyến nghị:
- Nếu thích mặc rộng, tăng 1 size so với thông thường.
- Nếu cần chính xác, hỏi theo mã sản phẩm để kiểm tra tồn kho size/màu.
